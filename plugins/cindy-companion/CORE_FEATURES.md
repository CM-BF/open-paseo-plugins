Upstream: `makecindy/cindy`, revision `118767c987f518286ae10a506a54287c3dc2a560`.

The requested scope was expanded on 2026-10-29: enumerate and port Cindy's core companion experience, particularly preset teammates and ad hoc group discussion. Fidelity includes source behavior, placement and visual style. This matrix supersedes the earlier settings-only scope. A working settings drawer is not completion of this matrix. Generic host APIs stay in the Paseo PR; companion behavior stays in this plugin. Upstream-watch separately tracks feature changes and recommends adoption without silently implementing future changes.

Statuses: **verified** requires real installed-host evidence; **partial** means a functional subset; **implementing** means source/tests exist but installed acceptance is pending; **open** means not yet implemented. An upstream design proposal is not counted as deployed functionality. - Root: feature matrix, host entry/group screen, preset importer, installed acceptance, review and release integration.
- `cindy_companion`: original preset and group frontend, catalog/resource extraction, provenance and UI tests.
- `cindy_core`: deterministic group execution, runtime adapters, native stop, disabled draft integration and race tests.
- `paseo_capabilities`: exact-turn steer host API after completing upstream-watch review mode; root owns upstream installation/registration.

Preset assets retain their original manifests and rights records.
