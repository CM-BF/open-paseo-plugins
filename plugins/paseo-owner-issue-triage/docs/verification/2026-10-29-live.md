The daemon's final source is `~/.paseo/local-plugins/paseo-owner-issue-triage`. Paseo 0.13.2 rejects an already-configured runtime ID; source replacement required removing this plugin registration and reinstalling it. State was preserved. To switch/reinstall that source:

```sh
paseo plugin remove paseo-owner-issue-triage
paseo plugin install "$HOME/.paseo/local-plugins/paseo-owner-issue-triage" --id paseo-owner-issue-triage
```

For rollback, use the recorded `source.json` and reinstall its directory only while that development checkout still exists. Prefer restoring a known committed plugin copy to a stable directory. Since this was a first install, disabling/removing this plugin returns the host to its prior plugin set; local data remains available. No unrelated plugin or daemon setting was changed.
