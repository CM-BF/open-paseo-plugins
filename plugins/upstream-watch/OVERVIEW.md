上游更新记录每个插件参考的 GitHub 项目、功能目录或 fork 上游，定期检查变化，并让你一键创建负责适配的 agent。一个插件可以关联多个上游，每条关联保留已采用或已处理的 commit。

在“发现来源”中读取插件的 UPSTREAM.json、SOURCE.json 和 Git remote 候选，确认开发目录与基线后添加；也可以手动登记仓库、分支、关注文件或目录。默认每天只读检查，不调用模型。变化显示在侧栏数量与列表中，直到你明确标记已处理或跳过。

“开更新 agent”使用你选定的已有工作区、模型和原生权限设置，带上固定版本、相关提交、路径及适配说明。创建 agent 不会推进已处理基线。重复点击共用任务，未知创建结果保留原身份供核对后重试。

需要 Paseo 0.12.0。GitHub 访问优先使用本机 gh 的已有登录，否则匿名访问公开仓库；失败和限流会显示原因，并保留上次成功结果。关注路径为文件或目录前缀，不使用 glob。差异截断、历史分叉等情况显示需要核对。

提醒是应用内徽标和持久化列表。Paseo 0.12 没有公开通用系统推送接口。直接升级安装源仍使用 Paseo 原生插件更新功能。本插件不会自动执行上游脚本、安装、发布或合并变更。
