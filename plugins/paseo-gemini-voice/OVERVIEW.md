让 Paseo 的听写和语音对话都支持中文。输入框里的麦克风听写、语音对话里你说的话，都由 Google Gemini 识别，一句话里中文和英文混着说也能认出来，英文单词、产品名和代码术语保持原样。语音对话里 Agent 的回复用 Gemini 或 macOS 朗读，可以读中文。手机、网页和桌面客户端都用同一套设置。

Paseo 自带的本地语音模型只支持英语。这个插件在运行 Paseo 的电脑上开一个只监听 127.0.0.1 的本地转发，Paseo 把录音和要朗读的文字发给它，它再交给 Gemini 处理。

## 需要准备

- Gemini API key：在 Google AI Studio 创建。不绑卡可以用免费额度，但免费层的请求可能被 Google 用来改进产品。给项目绑定结算账号后不会这样使用，额度也更高。Google AI Pro 订阅每月附带 10 美元 Google Cloud 额度，可以在 Google Developer Program 里领取后抵扣 Gemini API 费用。
- Paseo 0.12 或更新版本。写入配置后需要重启一次 Daemon，手机上也能操作：设置 → 主机 → 重启 Daemon，正在运行的 Agent 会继续运行。

## 设置

在 **设置 → 插件 → Gemini 中文语音** 中操作，也可以在输入框里输入 `/gemini-voice` 打开。

- **API key**：保存在运行 Paseo 的电脑上（权限 0600 的文件），客户端只能看到前后四位。也可以改用 Daemon 环境变量 `GEMINI_API_KEY`。
- **用示例音频试一下**：把一段内置的中英混说录音发给 Gemini，不用重启就能看到识别结果。
- **写入配置 / 恢复**：写入时先备份 Paseo 的 `config.json`，只改听写和语音对话的语音设置；恢复时还原成原来的值。停用或删除插件前请先恢复，否则听写和语音对话会失败。
- **识别模型**：默认 `gemini-3.5-transcribe`，是 Gemini 的专用语音识别模型。主模型不可用、超时或额度用完时，改用备用模型 `gemini-3.5-flash-lite`。
- **整理方式**：整理模式去掉口头禅、重复和改口；逐字模式保留原话。
- **语言**：默认自动识别，适合中英混说。也可以提示普通话或英语。
- **专有词**：提高产品名、人名和代码术语的识别准确率，默认包含 Paseo、Claude Code、Codex 等常用词。
- **朗读引擎**：Gemini（默认 `gemini-3.8-flash-lite-tts`，声音自然，可选 30 种音色）或 macOS 本地朗读（离线、免费、更快，用系统自带的中文音色）。Gemini 朗读出错或额度用完时，自动改用 macOS 朗读。**试听**会在当前设备上播放一句中英混合的话。

## 发送的内容

听写和语音对话的录音（Paseo 每 15 秒或每说完一句切一段）连同专有词列表，以及语音对话里 Agent 要朗读的文字，发送到 Google 的 Gemini API。请求关闭了 Gemini 的交互存储（`store: false`），免费层的数据使用规则仍然适用。几乎无声的片段不会发送。选择 macOS 朗读时，朗读的文字不离开这台电脑。插件只在内存里保留最近一次识别和朗读的时间、模型和开头一段文字，用于设置页显示。

## 限制

- 听写的文字按段出现：说完或每满 15 秒识别一段，不会逐字显示。段与段之间会多一个空格。
- 某一段识别失败时，整次听写会报错。App 会保留录音，可以点重试。
- 语音对话里，Paseo 要等一整段朗读音频生成完才开始播放。插件会把长回复切成短句并行合成，但 Agent 一次说很长时，第一句出声前仍会有几秒等待。
- macOS 朗读只在 Daemon 运行在 Mac 上时可用。
