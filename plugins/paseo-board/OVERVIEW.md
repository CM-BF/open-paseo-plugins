# Boards

Boards 把与 agent 的交流放到一块持续更新的自由画布上。画布可以是解释、图表、动画、模拟器或任何交互页面，由 agent 根据任务自行构建。

右键、选中文字或 Option / Alt 拖动框选完成后，直接在鼠标旁输入。Enter 发给主会话；⌘ / Ctrl + Enter 发给当前旁支（没有时创建）；⌘ / Ctrl + Option / Alt + Enter 新建并选中旁支。也可在输入框旁切回已有旁支。点击框外关闭。无需区分提问和修改。Fork 只隔开会话上下文，同样能按你的要求直接修改共享 Board。输入框保留原生右键菜单；处理中标记有轻量动画，界面区分送达、回复和有依据的落实。

决策面板保留 agent 在工作途中自行作出的重要选择，区分明确记录、观察到的变化和待核实的推断，并显示来源。它不是一张等你批准的任务清单。

新的问题标记会跟随组件移动，内容收起后可留在可见标题或容器上。右侧讨论索引保留所有问题，点击即可定位和继续交流。原组件已删除、无法确认位置，或是旧版引用时，讨论仍可打开，并保留提问时的原文和截图。

进入 Board 后，可自动定位到最近未看的更新；顶部的上一处 / 下一处会直接移动到相应区域并短暂高亮。多位 agent 的更新集中记录，首页显示每张 Board 的未看数量。输入、拖动或选区期间暂缓自动跟随，手动浏览时新更新不会抢走当前位置。

桌面版支持完整的自由交互。手机提供摘要、决策和交流的兼容界面。后台事件可以通过 paseo-async-shell 更新画布，无需持续运行模型；只有需要解释或行动时才唤醒 agent。

需要 Paseo 0.13.2 或更高版本，不设版本上限。数据、历史和选区快照保存在运行 daemon 的机器上。提问会把相关画布内容和快照发送给所选 agent 的模型提供商。新会话自动获得 Board 工具，现有会话也能使用本地命令行。
