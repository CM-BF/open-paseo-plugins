主模型被明确限流时，使用 Codex 提供商的 `gpt-6.1-sol`、`ultra` 思考强度继续任务。适用于 Claude 和 Codex 会话，需要此 Codex 模型可用且有剩余额度。

Claude 限流时，在同一工作区创建 GPT 备用会话，共用项目文件，并用对话快照和工作进展接着处理。快照提供交接上下文，Claude 的内部会话状态不会迁移给 GPT。原来的 Claude 会话保留。额度重置且双方空闲后，把最新进展交回原会话继续；任务已完成时，仅交付结果，不另起新工作。

Codex 限流时，在原会话直接切换模型；额度重置且会话空闲后，恢复原模型和思考强度。没有重置时间时，每 5 分钟检查恢复条件。

在 **设置 → 插件 → 自动模型切换** 中启用或停用，查看并打开原会话和备用会话，检查预计重置时间和错误信息。原会话与备用会话的时间线也会显示交接状态。

停用会停止新的备用切换。Codex 在空闲时恢复原模型；已有的 Claude 交接仍需等待额度恢复且双方空闲后，才能交回进展。

配置和切换记录保存在本机，插件重载或守护进程重启后会继续处理。
